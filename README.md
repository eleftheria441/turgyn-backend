# Turgyn — сервер

Node.js 20 · Express · PostgreSQL

## Как устроено хранение

- `app_state` — все данные УК одним документом с номером версии. Два сотрудника не перезапишут правки друг друга: устаревшее сохранение получает отказ, и интерфейс подгружает свежую версию.
- `state_snapshots` — автоматические резервные снимки раз в час, хранятся последние 168 (неделя).
- `sessions` — входы сотрудников (14 дней) и жителей (60 дней).
- `audit_log` — журнал: входы, неудачные попытки, сохранения, смены паролей, выгрузки.

## Переменные окружения

Полный список с пояснениями — в `.env.example`. Обязательная одна: `DATABASE_URL`.

## Первый запуск

При пустой базе создаётся один директор с логином `ADMIN_LOGIN`. Если `ADMIN_PASSWORD` не задан, временный пароль выводится в лог сервера, и система потребует сменить его при первом входе.

## API для директора

- `GET /api/state/audit` — журнал действий
- `GET /api/state/export` — полная резервная копия в JSON
